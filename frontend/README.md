# Clio's Gambit - Frontend

A premium React-based dashboard for students, coaches, and admins of the Clio's Gambit chess academy.

## Tech Stack
- **React & Vite**: Fast development and optimized builds.
- **Chakra UI**: Modern, accessible component library.
- **Material UI Icons**: For consistent iconography.
- **Axios**: API communication.
- **React Router**: Navigation and authentication state management.

## Features
- **Ancient Wisdom UI**: A bespoke "Royal Chess" aesthetic with gold ornaments and serif typography.
- **Dynamic Dashboards**: Role-based access for Students, Coaches, and Admins.
- **Auth Integration**: Secure login and interactive forgot-password flow with auto-fill support.

## Installation & Running
```bash
# Install dependencies
npm install

# Run development server
npm run client
```

## API Connection
The frontend connects to the backend at `http://localhost:5000/api`. This can be configured in `src/api/client.js`.
